# Finago AI

**Finago AI** is a modern, intelligent financial advisor built to help users navigate the world of personal finance in India. Leveraging the power of Google Gemini AI, it provides personalized advice on budgeting, investing, and tax saving through a sleek, glassmorphic interface.

## 🚀 Key Features

- **AI Financial Advisor**: Real-time conversations with an AI tuned for the Indian financial landscape.
- **Intelligent Context**: Uses custom training data to provide accurate and relevant advice.
- **Premium Design**: Sleek, dark-mode interface with glassmorphic elements for a premium user experience.
- **Secure Authentication**: Simple and intuitive login flow for personalized data.

## 🛠️ Technical Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4.
- **AI Engine**: Google Gemini 1.5 Flash.
- **Backend API**: Serverless functions (Node.js).
- **Styling**: Modern CSS with custom animations and mesh gradients.

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- NPM
- Google Gemini API Key

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd finago
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment variables:
   Create a `.env` file in the root directory and add your API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 📜 Usage

1. Log in with your demo credentials.
2. Navigate to the **AI Advisor** tab.
3. Ask any financial question, such as "How can I start investing in mutual funds?" or "What are some common tax-saving sections under the Income Tax Act?"
